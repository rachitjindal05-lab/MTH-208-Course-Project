# MTH-208-Course-Project
**Title: Advanced Stock Market Analysis Dashboard**

**Description:**

This repository contains the codebase and documentation for an interactive R Shiny application developed for the MTH 208 course. Designed for advanced stock market tracking and quantitative financial analysis, the dashboard visualizes complex market trends and statistical data. In addition to the core application code **(app.R)**, this repository includes the formal project proposal, the comprehensive final research report, and an accompanying presentation detailing the underlying methodologies and insights.

## Core Functionality
The application serves as a dynamic financial analysis engine. While traditional stock charts offer static views, this Shiny dashboard leverages reactive programming to allow users to interact directly with the data. 

**Key Features Include:**
* **Interactive Data Visualization:** Dynamically generates complex financial plots (such as time-series charts and moving averages) based on user-selected parameters, tickers, and date ranges.
* **Statistical Computation Engine:** Processes raw financial datasets in the background to calculate key mathematical indicators, such as market volatility, daily returns, and historical performance metrics.
* **Reactive User Interface:** Features a clean, intuitive dashboard where user inputs immediately update the underlying statistical models and visual outputs without requiring page reloads or coding knowledge.

## Practical Use Cases
This dashboard is designed to transform raw market data into actionable insights, making it a valuable tool for several scenarios:
* **Quantitative Market Analysis:** Allows data scientists and financial analysts to observe historical trends and compute statistical risk factors associated with specific equities.
* **Educational Demonstration:** Serves as an interactive learning tool to visually demonstrate how market volatility and pricing models behave over time.
* **Algorithmic Strategy Research:** Provides a foundational platform that can be used to backtest quantitative trading strategies.
* **Data Science Portfolio Showcase:** Demonstrates a practical application of R programming, data wrangling, and UI/UX design to solve complex, real-world analytical problems.
